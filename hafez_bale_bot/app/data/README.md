# دیتاست حافظ
فایل `hafez_ghazals.json` باید اینجا قرار بگیرد (یا مسیر آن با `HAFEZ_DATASET_PATH` در `.env` تعیین شود).
ساخت فایل از متن شما: `python -m tools.import_hafez --input divan.txt [--interpretations interp.json]`
(فرمت ورودی در `python -m tools.import_hafez --help`). تا وقتی این فایل نباشد، دکمه فال پیام «موقتاً در دسترس نیست» می‌دهد و سهمیه کم نمی‌شود.
